# Roadmap

## Phase 1: Stabilization

- ตรวจ model IDs
- เพิ่ม unit tests สำหรับ storage, rich text และ exporter
- เพิ่ม integration tests สำหรับ AI providers
- เพิ่ม global error boundary
- เพิ่ม retry และ timeout UI

## Phase 2: Backend Foundation

- NestJS หรือ FastAPI backend
- Server-side AI proxy
- Authentication
- PostgreSQL database
- Project CRUD API
- Rate limiting และ audit logs

## Phase 3: Writing Safety

- Autosave snapshots
- Version history
- Undo/redo ครอบคลุม AI actions
- Conflict detection
- Backup scheduler

## Phase 4: Collaboration

- แชร์โปรเจกต์
- Roles and permissions
- Comments
- Real-time collaboration

## Phase 5: Production

- CI/CD
- Error monitoring
- Analytics
- Secret management
- Deployment documentation
