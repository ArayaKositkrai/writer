# Features

## Authentication

ปัจจุบันเป็น local authentication สำหรับเข้าใช้งานหน้าหลัก ยังไม่มี backend session หรือ account จริง

## Idea Base

- กำหนด genre
- seed idea
- target readers
- chapter count
- words per chapter
- tone
- AI mode
- author notes

## Pitch Lab

- สร้าง pitch หลายตัวเลือก
- เลือก pitch หลัก
- เก็บ hook, style และ risk

## Story Bible

- premise
- world rules
- style guide
- characters
- timeline
- mysteries
- canon memory

## Chapter Board

- จัดการโครงตอน
- ระบุ goal, conflict, outcome และ cliffhanger
- ติดตามสถานะ planned, drafting, reviewing, needs revision และ main

## Chapter Writer

- Rich text editing
- สร้าง draft ด้วย AI
- rewrite และ review
- บันทึก main text
- อัปเดต canon

## AI Modes

- Mock: ไม่เรียก API
- Manual: สร้าง prompt เพื่อให้นำไปใช้เอง
- Live API: เรียก Gemini, OpenAI หรือ Ollama จริง

## Export

- DOCX รายตอนและทั้งเล่ม
- Markdown
- JSON backup/import
